# NIGHT SHIFT — fresh-player protocol (60 minutes, one observer)

The single highest-leverage hour left. The audit proves fairness; this
proves readability. Run on a local build or the secret-URL page — never
the public page (spoilers). Record the screen + audio with consent.

## Setup (5 min)

- Clean profile, game open at the title screen. Observer shares screen-read
  duty: silent except for hints (below) and time checks.
- Say exactly this: "Play as far as you can. Think aloud — every guess,
  every reread, say it. There are no wrong observations, only data."
- Do NOT explain rules, theme, or structure. Deflect questions with
  "what does the screen tell you?"

## Tasks (40 min)

1. **Days 1–2, blind.** No hints unless stuck 5+ minutes on one screen.
   A hint is a question, never an answer ("which rows agree with each
   other?", "what do the two HUMAN stamps have in common?").
2. **Night 2+ if reached.** Let the amendment land untouched. Do not
   explain contested; the tag must do it.
3. **Stop at 40 min** wherever they are, even mid-day.

## Observer checklist (tick + timestamp, don't interpret live)

- [ ] Day-1 filing time (start → File press): ___:___
- [ ] Row(s) cited before filing (which precedent convinced them?): ______
- [ ] Did they reread the riddle after seeing the docket? (y/n)
- [ ] Day-2: filed on pattern or on vibe? (their words: ______)
- [ ] Liar day reached? Spotted the odd row unprompted / after flagging /
      filed past it?
- [ ] Amendment reaction (verbatim first sentence): ______
      → surprise (gotcha — telegraph failed) or dread (worked)?
- [ ] Contested paraphrase after one night (their words): ______
- [ ] Clock noticed without prompting? (y/n) Oath understood? (y/n)
- [ ] Any tap-everything or random filing? When, and what preceded it?

## Debrief (10 min, exact questions)

1. "What is ARIA's rule on the day you reached — in your own words?"
2. "Was there a strike that felt unfair? Which filing, and why?"
3. "What is the night shift *for* — why does the game make you do it?"
4. "Who is VALE, and how do you know?" (if finale reached; else skip)
5. "What would you tell a friend this game is?"

## Red flags → fixes (decide within 24h, patch in voting month)

| Signal | Fix |
|---|---|
| Files in <60s on day 1 citing vibes, not rows | Riddle carries the deduction; docket is decoration → strengthen day-1 HUMAN contrast (rerun audit with new confuser family) |
| Files past the liar twice | Odd-row salience fails → flag pulse on tap? ARIA aside on day 4 open? |
| Amendment reads as gotcha (surprise language) | Move telegraph earlier (night-open line, not explainer) |
| Can't paraphrase contested | Inline tag rewrite (verb first: "CALL IT RIGHT: double pay") |
| Random filing after a fair strike | Verdict failed to teach → ledger line names the miss harder; check nudge fired |
| "I don't know what the night is for" | Act structure unclear → title-screen steps already say it; consider day-2 ARIA bridge line |

## Reporting

Write it up as devlog D3-results within 48h, whatever happened. Include:
filing times, cited rows, verbatim amendment reaction, and exactly what
changed (commit hash) or why nothing did. A test you can't fail isn't one.
